# Excel-MollaAI-Sales-Dashboard-Project
Excel-MollaAI-Sales-Dashboard-Project is a project where I use excel to clean data. After Cleaning Data, I make pivot tables from that processed data. Then, I turn those pivot tables into pivot charts. Finally, I add slicers by connecting all the charts.
